# SLE-ID 星随 · 参赛演示拍摄脚本（≤3 分钟）

定位：三端真实 SLE 链路 + 真实写卡 + 卡片认证 + 通行事件 + GPIO 执行 + 平板/管理端展示。
目标：**一遍拍完、可重复**。总时长约 2 分 45 秒。

## 0. 拍摄准备（不计入时长，提前做好）

- 三块板通电，确认 A 串口日志 `[A][dual] B ready=1; Card ready=1`；B 接 COM6、Card C 接 COM14、A 接 COM8。
- 平板 SleKey App 已配对，卡片 `DC-33E83A56` 主页显示"已写入"。
- 后端运行中（`0.0.0.0:8080`），管理端事件页打开。
- 三个串口终端并行滚动 + 平板界面 + 后端事件页，画面布局提前摆好。
- GPIO10 接 LED（排针第 34 脚），LED 位置醒目。
- 卡片 C 写卡窗口未开（写卡段再开，避免计时混乱）。

## 6. 拍摄要点与避坑

- **一次拍完**：按 8/18 文档，三串口 + LED + 平板 + 管理端四画面并行，一气呵成。
- **认证窗口**：`auth start` 后 15 秒内必须 `demo enter`，脚本里两命令连发。
- **写卡窗口**：`write unlock` 60 秒，写卡段不要停顿。
- **LED 触发**：GPIO10 脉冲在 `auth consume` 后出现，提前对好焦点。
- **日志过滤**：平板 `hilog -x | grep SLEKEY`；B/A 串口直接滚动即可。
- **失败预案**：若某段失败，只重拍该段，剪辑拼接；不要伪造日志。
- **真实时间参数**：`auth start` 的时间戳用拍摄当天当前 Unix 时间（B 无 RTC）。
