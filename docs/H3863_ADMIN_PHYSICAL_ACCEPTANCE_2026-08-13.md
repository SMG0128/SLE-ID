# H3863 A/B 与管理端实体联调验收记录

日期：2026-08-13

## 结论

两块 BearPi H3863 分别运行 Detector A、Detector B，已完成与本地管理端的实体联调。B 网关心跳、基础策略下发、事件上报、未授权报警、报警处理、USB 断线恢复以及 A 复位恢复全部通过。

## 通过项目

1. B 合法网关识别与双向心跳，首页显示“心跳正常”。
2. 基础策略连续下发两次成功，硬件策略版本递增。
3. A 执行 `demo enter` 后，B 返回决策，管理端事件中心收到事件。
4. 未授权处理设为报警后，报警中心收到未授权报警。
5. 报警处理后状态与首页统计正确更新。
6. B USB 拔插后 COM、心跳、SLE 和事件链路恢复。
7. A 复位后重新出现 `bridge ready`，新事件正常上报且未被误判重复。
8. 无 Card C HMAC 会话时返回 `reason=1`、`exec=0`，GPIO10 未误动作。

## 说明

- B 板复位时 USB 串口通常保持枚举，且心跳恢复很快，管理页面未必捕获瞬时离线；本轮以实际 USB 拔插覆盖断链恢复。
- “心跳 0s”表示最近一次心跳不足 1 秒；当前设备页面不是连续刷新，展示不够直观但不影响链路判断。
- 新开后端返回 `EADDRINUSE 127.0.0.1:8080`，证明原后端实例仍在运行。本轮未执行原实例真正停止后的配置与数据恢复验收。
